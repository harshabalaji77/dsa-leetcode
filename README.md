## LeetCode Data Structures and Algorithms

A comprehensive collection of LeetCode solutions organized by data structure and algorithm type. This repository contains Java implementations for various coding problems to help prepare for technical interviews.

### 📁 Repository Structure

```
Leetcode-dsa/
├── Arrays/                 # Array-based problems
├── Linked List/           # Linked List problems
└── Strings/               # String manipulation problems
```

### 🚀 Categories

### Arrays
Contains solutions for array-related problems including:
- **Two Sum** - Find two numbers that add up to a target
- **3Sum** - Find all triplets that sum to zero
- **Maximum Subarray** - Find the contiguous subarray with the largest sum
- **Best Time to Buy and Sell Stock** - Maximum profit from stock trading
- **Container With Most Water** - Maximize area between two lines
- **Trapping Rain Water** - Calculate trapped rainwater
- **Search in Rotated Sorted Array** - Binary search in rotated arrays
- **Merge Sorted Array** - Merge two sorted arrays in-place
- **Remove Duplicates from Sorted Array** - Remove duplicates in-place
- **Rotate Array** - Rotate array to the right by k steps
- And more...

### Linked List
Solutions for linked list data structure problems:
- **Add Two Numbers** - Add numbers represented as linked lists
- **Reverse Linked List** - Reverse a singly linked list
- **Merge Two Sorted Lists** - Merge two sorted linked lists
- **Linked List Cycle** - Detect cycles in linked lists
- **Middle of the Linked List** - Find the middle node
- **Remove Duplicates from Sorted List** - Remove duplicates from sorted list
- **Swap Nodes in Pairs** - Swap every two adjacent nodes
- **Reorder List** - Reorder list to alternating pattern
- And more...

### Strings
String manipulation and algorithm solutions:
- **Valid Parentheses** - Check for balanced parentheses
- **Longest Palindromic Substring** - Find the longest palindrome
- **Valid Anagram** - Check if two strings are anagrams
- **Roman to Integer** - Convert Roman numerals to integers
- **Integer to Roman** - Convert integers to Roman numerals
- **Group Anagrams** - Group anagrams together
- **Reverse String** - Reverse a string in-place
- **Reverse Words in a String** - Reverse word order in a string
- **Longest Palindrome** - Find the longest palindrome that can be built
- And more...
